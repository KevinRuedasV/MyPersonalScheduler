# MyPersonalScheduler

Frontend de la aplicación MyPersonalScheduler.

## Stack

- Angular 22
- TypeScript
- Tailwind CSS

## Development

Instalar dependencias:

```bash
npm install
```

Arrancar el servidor de desarrollo:
```bash
npm start
```

La aplicación estará disponible en:
http://localhost:4200/

## Build

```bash
npm run build
```
